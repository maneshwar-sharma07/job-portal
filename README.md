# job-portal
A responsive job portal website built using HTML and CSS, featuring a modern UI for browsing jobs and viewing opportunities across multiple categories.
Job Portal Website is a front-end web project created using HTML and CSS. The platform is designed to simulate a real-world job portal where users can browse job listings, view job information, and explore career opportunities through a visually appealing and responsive interface. The project focuses on clean UI, structured layout, and mobile-friendly responsiveness.

Key Features:

Responsive design for mobile, tablet, and desktop

Modern and professional UI

Job listing cards with details

Clean layout and smooth user experience

Beginner-friendly front-end project
